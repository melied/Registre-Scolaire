## 1. شجرة المشروع

```
E:\tlmid\
│
├── registre_presence_trilingue.html   ← التطبيق الكامل (ملف واحد مستقل)
├── Setup_RegistreScolaire.exe         ← مثبت البرنامج (معالج: التالي / التالي / إنهاء)
├── RegistreScolaire.exe               ← مشغّل البرنامج (أيقونة سطح المكتب)
├── Desinstaller.exe                   ← إلغاء التثبيت
│
├── icon-512.png                       ← أيقونة 512 (قبعة + كتاب + صح)
├── icon-192.png                       ← أيقونة 192
├── apple-touch-icon.png               ← أيقونة 180 (آيفون)
├── icon.svg                           ← نفس الأيقونة بصيغة متجهة
├── app.ico                            ← أيقونة الويندوز (تُستخدم عند الترجمة فقط)
│
├── manifest.webmanifest               ← ملف PWA (التثبيت على الهاتف)
├── sw.js                              ← Service Worker (العمل دون إنترنت للنسخة المثبتة)
└── README.md                          ← هذا الملف
```

ملفات التثبيت على الجهاز (بعد التثبيت):

```
%LocalAppData%\RegistreScolaire\
├── registre_presence_trilingue.html
├── RegistreScolaire.exe / Desinstaller.exe
├── icon-512.png / icon-192.png / apple-touch-icon.png / icon.svg / app.ico
└── manifest.webmanifest / sw.js
```

> البيانات (الأفواج، التلاميذ، الحضور) محفوظة في متصفح Chrome بقاعدة **IndexedDB**،
> وتبقى بعد إغلاق البرنامج أو إعادة تشغيل الحاسوب.

## 3. المزايا المنفذة

**اللغات والواجهة**
- عربية / فرنسية / إنجليزية بتبديل فوري، والاختيار محفوظ
- دعم RTL للعربية وLTR للفرنسية والإنجليزية تلقائيا
- كل الأزرار والجداول والرسائل والإحصائيات والطباعة باللغة المختارة
- الأرقام والتواريخ دائما لاتينية (12/02/2026) حتى بالعربية
- الوضع الليلي بزر في القائمة الجانبية

**التسيير اليومي**
- معلومات المؤسسة الكاملة (11 حقلا)
- أفواج تربوية: إضافة/تعديل/حذف/نسخ/اختيار/بحث
- تلاميذ: ترقيم تلقائي، بحث، ترتيب، فلترة، نقل بين الأفواج، استيراد/تصدير CSV
- المناداة اليومية: حاضر / غائب / متأخر + مبرر + وقت الوصول + المدة المحسوبة + ملاحظات
- جدول حصص أسبوعي لكل فوج يُستخدم تلقائيا لحساب التأخر
- ملاحظة يومية خاصة بكل فوج وتُطبع مع السجل

**السجلات والإحصائيات**
- سجل الغيابات والتأخيرات (يتحدث تلقائيا)
- بطاقة فردية لكل تلميذ مع رسم بياني
- السجل الشهري (✓ / AJ / ANJ / R) والسجل السنوي (سبتمبر ← جوان)
- لوحة قيادة: إحصائيات اليوم/الشهر/السنة + الأكثر غيابا
- تنبيه الغيابات المتكررة (عتبة قابلة للضبط) + منحنى نسبة الحضور (12 أسبوعا)

**الحماية والنسخ**
- كلمة مرور محلية تقفل الإعدادات وعمليات الحذف
- نسخ احتياطي تلقائي داخلي (لقطات) + تصدير JSON وCSV وZIP + استعادة
- طباعة اليومي والشهري والسنوي وبطاقة التلميذ **وورقة فارغة للتوقيع اليدوي**

**التثبيت**
- مثبت ويندوز حقيقي بثلاث لغات، اختصارا سطح المكتب وقائمة ابدأ، وظهور في البرامج المثبتة
- نسخة PWA للهاتف، والملف الواحد يعمل مباشرة دون تثبيت

## 5. التثبيت والاستعمال

1. شغّل `Setup_RegistreScolaire.exe` واتبع الخطوات (التالي / التالي / إنهاء)
2. افتح البرنامج من أيقونة سطح المكتب **Registre Scolaire**
3. اختر اللغة من أسفل القائمة، أدخل معلومات المؤسسة من الإعدادات
4. أنشئ فوجا، أضف التلاميذ (أو استوردهم CSV)، ثم ابدأ المناداة اليومية
5. من النسخ الاحتياطي: صدّر نسخة JSON/ZIP دوريا وخزّنها خارج الحاسوب
